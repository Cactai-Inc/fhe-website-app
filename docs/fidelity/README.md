# docs/fidelity

Raw thread transcripts, pasted verbatim by the owner.

**What belongs here:** the actual contents of a thread, unedited, unsummarised.

**What does not:** anything a thread wrote about itself. Reports, ledgers, handoffs and
session records are thread-authored — they are what a thread *chose* to record, which is
exactly the failure this folder exists to close. Those live in `docs/orch/`,
`docs/reports/` and `docs/reference/`.

**Why it exists.** On 2026-09-06 an owner ruling on the contract signing model was
refined mid-discussion, the thread in that conversation captured only the earlier version
— into a migration header rather than the change-order ledger — and shipped against it.
Five weeks later a second thread read that header as current intent, resolved a product
question inside a security task, and the consequence surfaced on a live lease that could
no longer be edited without destroying a client's signature. Nothing in the thread-authored
record caught it, because the thread-authored record was the thing that was wrong.

A transcript cannot be selectively remembered.

**Naming:** `THREAD-<THREAD-ID>-<YYYY-MM-DD>.md`
