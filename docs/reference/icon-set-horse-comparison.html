4 · The real question — do they sit together?

Lucide is a stroked set on a 24px grid. Phosphor regular is a heavier, partly-filled set on a 256px grid. Put one Phosphor icon in a Lucide rail and it will not match. Same page, same size, same colour:

Phosphor light is the closest match to Lucide's stroke weight. If we take only the horse, light is the weight to take. If the mismatch still shows, the honest options are to move the whole rail to Phosphor, or to keep Lucide and accept that one icon is the odd one out.
