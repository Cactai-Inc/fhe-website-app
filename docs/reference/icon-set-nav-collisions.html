What actually separates them

Phosphor — 1,512 icons, six weights (thin → duotone) from one design. The weight axis is the real asset: the same icon can be quiet in the rail and emphatic on a page without swapping files. It has barn, farm and horse, which no other set here offers together.

Material Symbols — ~3,900 icons, three styles, and three variable axes (fill, weight, grade, optical size). Far larger, and the variable font means one file covers every state. It is also unmistakably Google's UI language, which is the thing to weigh against a stable's brand. No horse, no barn — agriculture is a tractor.

Rendered at 22px. In the rail these sit at 17–18px, so prefer whichever still reads when it is smaller than this.
