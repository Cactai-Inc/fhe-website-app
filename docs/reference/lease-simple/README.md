# HORSE_LEASE_SIMPLE — the stripping worksheet

Three files, for one conversation at a kitchen table.

| File | What it is |
|---|---|
| [RENDERED-LEASE.md](RENDERED-LEASE.md) | The lease as it currently stands, in full prose, every clause numbered. Read this. |
| [WORKSHEET.md](WORKSHEET.md) | One row per clause, with a blank Keep / Cut column. Mark this. |
| [WORKSHEET.csv](WORKSHEET.csv) | The same rows, for a spreadsheet. |
| [CANDIDATES.md](CANDIDATES.md) | What comes out together, and what it costs. Observations only. |

`HORSE_LEASE_SIMPLE` is a byte-for-byte copy of `HORSE_LEASE_V2` — 22 sections, 144 clauses,
117 fields, verified identical. It gets simple by deletion, which keeps language that has already
been through legal review.

**Nothing in this folder has been decided.** The Keep / Cut column is blank on all 144 rows.

Method and what was verified versus inferred: [TASK-LEASESIMPLE-REPORT.md](../../reports/TASK-LEASESIMPLE-REPORT.md).
