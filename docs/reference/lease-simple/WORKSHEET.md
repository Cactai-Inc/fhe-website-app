One row per clause, in document order. Clause numbers match
[RENDERED-LEASE.md](RENDERED-LEASE.md) — read the prose there, mark the decision here.

**22 sections · 144 clauses · 117 fields.** No content decision has been made in this document.

## The four dependency classes

| Class | Meaning |
|---|---|
| `standalone` | Nothing else in the lease reads this clause or its answers. It can be cut on its own. |
| `DEPENDED-UPON` | Something else breaks if this goes. The **Depends on** column names what, and how. |
| `PROTECTIVE` | The clause carries legal protection. What is lost is stated in full. Do not cut without counsel. |
| `PROTECTIVE + DEPENDED-UPON` | Both. |

### How a cut breaks something

Cutting a clause removes the questions attached to it. Any gate that reads one of those questions
then reads an empty value, and the engine treats empty as “no answer”. Three things can follow, and
the **Depends on** column says which:

* **stops printing for good** — the gate can never be satisfied again. The other clause silently vanishes.
* **starts printing unconditionally** — the gate accepts an empty answer (`equals ["NO",""]` is common
  in the insurance section), so the other clause now always prints.
* **its gate changes meaning** — the outcome now turns on the remaining answers alone.

A blank `{{TOKEN}}` is the fourth failure: the sentence still prints, with a hole in it.
