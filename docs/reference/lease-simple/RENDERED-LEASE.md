**How to read this document**

* Every clause is numbered `§section.clause` — for example **§13.26**. The worksheet uses the same numbers.
* All **144** clauses appear, in document order, whether or not they print in the configuration above.
* Clauses that **would not print** in this configuration are shown indented and marked
  `— DOES NOT PRINT HERE —` with the condition that would bring them in. They are still shown in full
  so nothing is decided about a clause without reading it.
* `⟨not collected in this configuration⟩` marks a token whose field is switched off by the answers above.
* Composite inputs (fee schedule, medication schedule, week grid, location, contact list) are shown as
  plain text. The application draws them as small tables; the words are the same, the layout is not.
