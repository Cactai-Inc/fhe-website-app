the next sign-in produce a fresh, set-stamped set. The actions below use existing
functions only.

### Action A — activated account (Audrey). RUN BY STAFF AFTER OWNER APPROVES.

```sql
-- Void every unsigned (non-executed, non-void), set-NULL document for the
-- activated contact. On their next sign-in generate_my_onboarding_documents
-- soft-deletes these and regenerates each with a delivery_set_id.
-- Run as a staff/admin account (void_document requires auth.uid() + staff/party).
SELECT void_document(d.id, 'Regenerate into a delivery set (fix round 3 item 3)')
  FROM documents d
 WHERE d.contact_id = '7259f6bb-7368-4884-8629-70e277520316'  -- Audrey Dropsy
   AND d.deleted_at IS NULL
   AND d.delivery_set_id IS NULL
   AND d.status NOT IN ('EXECUTED','VOID')
   AND coalesce(d.workflow_state,'') <> 'void';
```
