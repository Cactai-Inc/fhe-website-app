## 4. WHAT TO BUILD
### 4a. Migration `…_reports_are_snapshots_with_one_current_per_period.sql` (dry-run first)
1. `reports` + `reports_display_code_seq` + trigger `BEFORE INSERT … EXECUTE assign_display_code('RPT-','reports_display_code_seq')` + the partial unique index `reports_one_current` — **exactly contract §7.1**. RLS: RESTRICTIVE `org_id = current_org()`; PERMISSIVE SELECT/INSERT/UPDATE for `has_staff_access()`; **no DELETE policy; no member policy.**
2. RPCs (`SECURITY DEFINER`, staff-gated, `REVOKE … FROM PUBLIC, anon` each):
   - `generate_report(p_report_key text, p_dashboard_key text, p_for_user_id uuid, p_period_key text, p_from timestamptz, p_to timestamptz, p_name text, p_inclusions jsonb, p_snapshot jsonb, p_formats text[], p_pdf_file_id uuid, p_csv_file_id uuid, p_reason text) RETURNS jsonb` — one transaction: (i) the existing row for the key in `('current','outdated')` → `status='superseded', superseded_at=now(), archived_at=now(), name = name || ' — superseded ' || to_char(now() AT TIME ZONE coalesce(config_value('OPS','TIMEZONE'),'America/Los_Angeles'), 'YYYY-MM-DD')`; (ii) INSERT the new row with `p_name` (the ORIGINAL name — the client passes the template result; if a superseded row existed, reuse ITS pre-suffix name so the name never drifts across regenerations); (iii) UPDATE the old row's `superseded_by_id`; return the new row. Validate `p_formats ⊆ {'pdf','csv'}`, that `p_pdf_file_id`/`p_csv_file_id` reference `files` rows with `owner_kind='org'` in the caller's org, and that `p_for_user_id` is NULL or a staff profile in the org.
   - `mark_reports_outdated(p_from timestamptz, p_to timestamptz, p_source text) RETURNS integer` — `UPDATE reports SET status='outdated', outdated_at=now(), outdated_reason=p_source, name = name || ' — outdated' WHERE status='current' AND org_id=current_org() AND period_from < p_to AND period_to > p_from`; returns the count. Callable by consumers' triggers (they run as the table owner — grant EXECUTE to `authenticated` and `service_role`; never `anon`).
   - `report_freshness_check(p_report_id uuid) RETURNS jsonb` — for each figure in `snapshot.figures` and `snapshot.business.figures` whose `source` names a registered figure function, re-run `fn(period_from, period_to)`, compare `value` (tolerance `0.005`); on any difference call `mark_reports_outdated(period_from, period_to, 'figures: ' || string_agg(key))` for THIS row only (an inner `UPDATE … WHERE id = p_report_id`); return `{fresh bool, changed text[]}`. ⚠️ The figure function is called by name through `EXECUTE format('SELECT %I($1,$2)', fn)` **only if `fn` is in the allowlist the app passes** (`p_allowed text[]` — the registry's figure fn names) — never an unconstrained dynamic call.
   - `list_reports(p_status text[] DEFAULT ARRAY['current','outdated']) RETURNS jsonb` — the company documents page's read: rows + `for_user` display name + file ids; ordered `period_from DESC, generated_at DESC`.
   - `company_documents() RETURNS jsonb` — the three lists of contract §7.5 in ONE call: `reports` (via the same predicate as `list_reports`), `company_files` (`files` `owner_kind='org' AND deleted_at IS NULL`), `shared_documents` (`documents d JOIN document_parties dp ON dp.document_id=d.id WHERE dp.contact_id = (SELECT company_contact_id FROM organizations WHERE id=current_org()) AND d.deleted_at IS NULL` — title, status, `display_code`, `executed_email_sent_at`), and `archived` (reports `status='superseded'`). **This reads `documents`; it writes nothing and adds no column** (the freeze).
3. `config_keys` row `('REPORTS','NAME_TEMPLATE','text', false, 'Report display name; tokens {report} {period} {variant}')`, seed `'{report} — {period} — {variant}'`. Editor: on the dashboards page's "Dashboards…" panel beside `OPS.TIMEZONE` (chunk D owns that panel — add the field there if D has merged; else the report names the follow-up: *"editor for REPORTS.NAME_TEMPLATE lands with D"*).

- **A client must never read a report**: RLS on `reports` has no member policy; test §9.5 proves 0 rows as a `USER`.
